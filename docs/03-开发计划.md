# NoteVault · 开发计划与阶段记录

> 开发节奏：每个阶段 = 开发 → 构建 → 测试/审查 → git 提交。所有阶段必须完成，不允许遗漏。

## 技术栈定案

- 前端：React 19 + TypeScript + Vite + Tailwind CSS 4 + zustand + react-markdown + mermaid + katex + highlight.js + lucide-react
- Web 宿主：Node.js 22 + 零依赖 node:http（`web/server.ts`）
- 桌面宿主：Tauri 2（Rust，单文件免安装 exe）
- 契约：`shared/types.ts`（channel/payload 两宿主 1:1）
