# NoteVault · 开发计划与阶段记录

> 开发节奏：每个阶段 = 开发 → 构建 → 测试/审查 → git 提交。所有阶段必须完成，不允许遗漏。

## 技术栈定案

- 前端：React 19 + TypeScript + Vite + Tailwind CSS 4 + zustand + react-markdown + mermaid + katex + highlight.js + lucide-react
- Web 宿主：Node.js 22 + 零依赖 node:http（`web/server.ts`）
- 桌面宿主：Tauri 2（Rust，单文件免安装 exe）
- 契约：`shared/types.ts`（channel/payload 两宿主 1:1）

### 阶段 5 · 审查修复清单（2026-11-20）

**已修复（安全）**
1. Markdown 内嵌 HTML 加 `rehype-sanitize` 消毒（扩展 schema 保留 details/mark/kbd/checkbox/KaTeX MathML/hljs class，剥离 script/事件处理器/javascript: URL）——实测富元素全部保留、脚本不执行；
2. HTML iframe sandbox 移除 `allow-same-origin`（脚本在隔离 origin 运行，交互保真不变，实测 ECharts 式报告正常）；桌面版配置非空 CSP；
3. Web 服务加固：Host 必须为本机（防 DNS rebinding）、API 校验 Origin/Sec-Fetch-Site/Content-Type（防 CSRF 启动本地程序）、请求体 ≤1MB；`/raw` 仅允许图片类；
4. 桌面 vault 协议：移除 CORS 通配头；`~abs/` 库外访问收窄为仅图片类。

**已修复（正确性）**
5. 切换笔记库清空标签与内容缓存（避免展示旧库同名文件）；自动刷新快照基线同步重置；
6. Rust 搜索 CRLF 行号偏移修复（换行归一化，与 Web 版一致）；
7. 桌面命令改 async + spawn_blocking（重 IO 不冻结 UI，vault_pick 不再假死）；
8. fs_snapshot 真实上报 truncated；fs_read 只读前 5MB（防超大文件 OOM）；fs_read 返回规范化路径；
9. Web `fs_stat` 非法路径不再返回库根 stat；dist 静态服务穿越检查补分隔符；
10. 符号链接/junction 两宿主统一跳过（防逃逸）；Rust 搜索相对路径改为遍历时累积；
11. `kindOf` 无扩展名分类与 Rust 对齐；`normalizeRelPath` 补齐控制字符拒绝；vault_info 相对路径 resolve；盘根库名两宿主对齐；
12. 前端小修：TopBar 双刷新、pickVault 异常捕获、QuickOpen 空列表钳位、Mermaid 临时节点清理、Outline MutationObserver rAF 去抖、以 `/` 开头的引用优先按库根解析；
13. Web 版 vault_set 维护 vault_history（与桌面版互通）；macOS 设置路径两宿主对齐；`tauri:smoke` Windows 可用；tsconfig.node 排除测试文件。

**已知限制（记录不改）**
- FileTree 无虚拟化（超大库过滤时可能卡顿）；排序算法两宿主略有差异（Web 拼音序 / Rust 码点序）；长会话内容缓存无上限（可手动刷新）；HTML 沙箱内 localStorage 不可用（保真需求可用「浏览器打开」）。
