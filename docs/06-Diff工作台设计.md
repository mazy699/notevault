# NoteVault · Diff 对比工作台设计

> 需求：对比代码 / SQL / 文本等文本类文件（不做 Word/Excel 二进制 diff）；
> 支持三种输入——①两个文件路径 ②直接粘贴两段文本 ③选 Git 仓库文件并按历史提交版本比较；
> 双栏并排查看（对标 IDEA / Beyond Compare），保持小巧轻量。

## 1. 工作台架构（采纳"侧边栏切换工作台"提案）

评估结论：**采纳**，形式为 **VS Code 式左侧活动栏（Activity Bar）**：

```
┌──┬─────────────────────────────────────────────────┐
│活 │  工作台区域（整体切换）                            │
│动 │  ┌─────────────────────────────────────────┐    │
│栏 │  │ 读取工作台（现状：树+标签+渲染器）           │    │
│  │  └─────────────────────────────────────────┘    │
│📖 │  或                                              │
│⚖️ │  ┌─────────────────────────────────────────┐    │
│  │  │ 对比工作台（本设计，整宽 Diff 视图）          │    │
│  │  └─────────────────────────────────────────┘    │
└──┴─────────────────────────────────────────────────┘
```

- 活动栏 44px 图标竖排：📖 读取工作台、⚖️ 对比工作台（未来新功能 = 新图标）；
- 读取工作台 = 现有全部能力原样迁移（顶栏/侧栏三页签/标签页/渲染器）；
- 对比工作台占满活动栏右侧全部区域（双栏 diff 需要宽度，不塞侧栏）；
- 主题切换移到活动栏底部（全局控件，两个工作台共用）；
- 每个工作台独立懒加载 chunk（对比工作台含 diff 引擎，不拖累首屏）。

被否掉的备选：diff 作为普通标签页打开（与文件标签模型冲突，输入区无处安放）；
diff 面板塞在侧栏（宽度不足，双栏对比没法看）。

## 2. 对比工作台布局

```
┌──────────────────────────────────────────────────────────────┐
│ [文件] [文本] [Git]        …      [并排|统一] [忽略空白☐] [⇄交换] │ ← 模式/视图工具条
├──────────────────────────────────────────────────────────────┤
│ 输入区（随模式切换）                                            │
│  文件: [旧: 文件路径______] [新: 文件路径______]                  │
│  文本: [旧文本 textarea] ⇄ [新文本 textarea]                    │
│  Git : [仓库路径______] [文件▾] [版本A▾] [版本B▾] [读取]          │
├──────────────────────────────────────────────────────────────┤
│ 统计: +12 新增 · -5 删除 · 3 处修改 · 2 折叠块                   │
├──────────────────────────────────────────────────────────────┤
│ ┌─────────── 旧 ───────────┬─────────── 新 ───────────┐      │
│ │ 12  function a() {       │ 12  function a() {       │      │
│ │ 13    return 1;          │ 13    return 2;  ←行内高亮 │      │
│ │ … 128 行未变更（点击展开）  │                          │      │
│ │ 140  const b = 2;  ✗删除  │       (空)               │      │
│ │ (空)                     │ 141  const c = 3;  ✓新增  │      │
│ └──────────────────────────┴──────────────────────────┘      │
└──────────────────────────────────────────────────────────────┘
```

- **并排（默认）/ 统一**视图切换；双栏共用一个滚动容器（天然同步滚动，无需 JS 对齐）；
- 变更行左右底色（旧删红 / 新增绿），**行内差异字符**更深一档底色；
- **折叠**：连续未变更行超过阈值时折叠为一条"⋯ N 行未变更"可点击展开的横条（默认上下文 3 行）；
- 统计条：新增/删除/修改行数与折叠块数；文件完全相同时显示"两个文件内容相同"；
- 大文件保护：> 20000 行跳过行内高亮；> 100000 行提示改用专业工具。

## 3. 三种输入模式

| 模式 | 输入 | 实现 |
| --- | --- | --- |
| 文件 | 两个绝对路径（记忆上次输入） | 新增 API `fs_read_abs`（只读文本，5MB 上限，GBK 回退） |
| 文本 | 两个 textarea（各占一半宽） | 纯前端对比；可给两侧命名（显示在结果条） |
| Git | 仓库路径 → 读取文件列表（`git ls-files`）→ 选文件 → 读取该文件提交历史（`git log --follow`）→ 版本 A/B 下拉（含"工作区"）→ `git show ref:path` 取内容 | 新增 API `git_ls` / `git_log` / `git_show`（只读命令，参数数组调用防注入，git 缺失时给出友好提示） |

- 文件模式额外提供"从当前打开的标签页选择"下拉（便利性，可空）；
- 交换按钮 ⇄：交换两侧输入并重跑；
- 忽略空白：比较时折叠连续空白，展示仍用原文。

## 4. Diff 引擎（自研渲染 + jsdiff 计算）

- 依赖：`diff`（jsdiff，~60KB）——Myers 算法算行级 LCS；**不用 Monaco**（数 MB，违反小巧原则）；
- 渲染自研：`diffLines → 行配对模型 → 折叠 → React 双栏表格`；
- 行配对规则：删除组与新增组相邻时按下标 zip 配对（多出的一侧留空行）；
- 行内高亮：配对行两侧都存在且内容不同时，用 `diffChars`（上限 500 对，超限跳过）；
- 折叠展开状态按块记录，展开不重算 diff。

## 6. 资源控制

- 对比工作台懒加载 chunk（含 jsdiff，约 60KB）；
- 行内高亮与渲染行数有上限，折叠默认开启（DOM 行数受控）；
- diff 纯前端计算，Web 宿主零新增开销；桌面版 git 调用为一次性子进程，无常驻成本。
