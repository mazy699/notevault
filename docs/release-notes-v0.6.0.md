# NoteVault v0.6.0

新增**密码工作台**：本地密码记录器 + 强密码生成器。第三个工作台（活动栏钥匙图标），
专为"公司邮箱 / 工号系统 / 数据库密码定期轮换"场景设计。

## 新增功能

### 凭证记录
- 条目字段：标题、分类（邮箱/工号系统/数据库/服务器/网站/其他，可自定义）、
  账号、密码、地址、备注；左列搜索 + 分类过滤，右侧详情；
- 密码默认遮蔽，显隐切换，**遮蔽状态直接点复制也会复制真实密码**；
- 强度指示（熵估算：弱/中/强/极强）。

### 密码历史
- 每次"更换密码"自动把旧密码记入历史（含停用时间）；
- 历史列表按"第 N 代"展示，可显隐、可复制；
- 生成器自动避让该条目"当前密码 + 全部历史"，避免与近期密码重复。

### 强密码生成器
- CSPRNG 生成，长度 8-128，四类字符开关（A-Z / a-z / 0-9 / 符号）；
- 排除字符集：内置"排除易混淆 O0oIl1|`'\" "预设 + 手动追加；
- 保证每个启用的字符类至少出现一次；会话内最近生成记录（点击复制）；
- 独立页签 + 内嵌更换密码面板两处入口。

### 导入 / 导出（迁移备份）
- **JSON**：完整迁移格式（含历史，无损）；
- **CSV**：表格快照（Excel 友好，BOM 防乱码）；
- **Markdown**：按分类分组的人读报表；
- 导入支持 JSON/CSV 自动识别，合并（同名同账号取较新）或替换整库；
- 桌面端导出走系统"另存为"对话框，Web 端走浏览器下载。

### 可选主密码加密
- 一键设置主密码：整库 **AES-256-GCM + scrypt** 加密存储；
- 主密码只存会话内存，刷新/重启后需重新解锁；
- **跨宿主互操作**：Web 版加密的库桌面版可直接解锁，反之亦然（已实测双向）；
- 锁态防护：未解锁时禁止一切写盘操作，防止误覆盖加密库。

## 修复

- 遮蔽密码复制到"圆点"的问题（复制始终取真值）；
- 解锁后加密标记丢失的问题（解锁后首次保存会把库静默转明文）；
- 桌面端文件对话框静默失败（save_text_file / vault_pick 改 blocking API）。
