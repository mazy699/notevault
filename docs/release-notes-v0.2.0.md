# NoteVault v0.2.0

v0.1.0 的功能增强版。新增**代码文件预览**与 **NSIS 安装版**，并附杀毒软件拦截的完整解决方案。

## 下载

| 文件 | 用途 |
| --- | --- |
| `NoteVault_0.2.0_setup.exe` | **安装版**（NSIS 向导，安装到当前用户目录，无需管理员权限） |
| `NoteVault_0.2.0_portable.exe` + `WebView2Loader.dll` | **免安装便携版**（两个文件放同一目录） |
| `checksums.txt` | 全部资产的 SHA256（供 IT 白名单/完整性校验） |

> 未签名 exe 可能被 Symantec 等企业杀软拦截（Unproven Insight）。
> 白名单指引与误报提交流程见仓库 `docs/05-杀毒软件与发布说明.md`；
> 被拦截时 Web 版（源码运行，无 exe）不受影响。

## 相对 v0.1.0 的变更

### 新增：代码文件语法高亮预览

- 新增 `code` 文件类型：**约 50 种扩展名**可直接在应用内打开并高亮显示
  - 语言类：`sql` `py` `java` `c/cpp/h` `cs` `go` `rs` `rb` `php` `swift` `kt` `scala` `lua` `pl` `r` `dart` `vb` 等
  - Web 类：`ts/tsx` `js/jsx` `vue` `svelte` `css/less/scss`
  - 脚本类：`sh/bash/zsh` `ps1` `bat/cmd`
  - 数据/配置类：`json` `yaml/yml` `toml`
- 树中代码文件使用独立的绿色 `<>` 图标；
- 全文搜索覆盖代码文件内容；
- 代码文件的工具条显示"代码文件（语法高亮预览）"，附带复制按钮与字符统计。

### 新增：NSIS 安装版

- 新增向导式安装包（默认安装到当前用户目录，无需管理员权限）；
- 便携版与安装版功能完全一致，按场景自选；
- Release 附带 `checksums.txt`（全部资产的 SHA256）。

### 文档

- 新增 `docs/05-杀毒软件与发布说明.md`：拦截原因分析、SEP 白名单步骤、
  Symantec 误报提交流程、代码签名证书说明。

## 升级说明

- 直接下载新文件替换旧文件即可（设置文件位于 `%APPDATA%/notevault/`，升级不影响）；
- v0.1.0 的便携包建议删除（云信誉独立，新旧版本互不影响）。
