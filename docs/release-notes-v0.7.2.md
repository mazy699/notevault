# NoteVault v0.7.2

小版本更新：密码工作台解锁后的手动 / 自动上锁能力，主密码不再限制长度。

## 新增

### 手动上锁
- 解锁状态下，密码工作台顶栏新增「上锁」按钮：点击立即清除会话主密码与内存明文，
  回到解锁卡片；磁盘上的加密库不受影响，其他工作台不受影响；
- 上锁后重新输入主密码即可恢复访问。

### 自动上锁（默认 30 分钟）
- 顶栏新增「N 分钟自动上锁」设置：默认 **30 分钟**，设为 **0 = 关闭**，上限 1440 分钟；
- 解锁状态下全局监听键鼠、滚动与输入活动，空闲达到阈值后自动上锁；
- 切换到读取 / 对比 / 工作日志工作台期间同样计时；
- 设置持久化到本地 `pw_autolock_minutes`，重启后继续生效。

## 调整

- **主密码取消 ≥8 位限制**：任意非空长度均可设置（强度由用户自行把握），
  设置/更改弹窗文案同步更新；
- 上锁不会触发写盘，加密库的锁态拒写保护继续生效。
