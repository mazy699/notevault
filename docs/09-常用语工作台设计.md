# 09 · 常用语工作台设计（Issue #12）

> 便签式常用语管理：只保存主动收藏的纯文本，支持分组、模糊搜索、一键复制、
> 拖动排序与 JSON 导入导出。作为 NoteVault 第 5 个工作台。

## 1. 存储选型：JSON 单文件（不用 SQLite）

| 维度 | JSON 单文件 | SQLite |
| --- | --- | --- |
| 预期规模 | 几十~数百条，后续增长到几千条仍可内存过滤 | 过剩 |
| 双宿主 | Web/Rust 既有原子写文件逻辑，零新依赖 | Web 需 sql.js/wasm 或 node:sqlite，Rust 需 rusqlite，双端实现成本高 |
| 搜索 | 前端内存模糊匹配（标题/正文/分组），千条级毫秒响应 | 需建表/索引/FTS，收益有限 |
| 迁移备份 | 导出即存储格式，复制一个文件即可 | 需导出层 |
| 拖动排序 | `order: string[]` 直接落盘 | 需额外排序列与迁移 |

**结论**：`%APPDATA%/notevault/snippets.json`（双宿主同路径、同格式），
环境变量 `NOTEVAULT_SNIPPETS_FILE` 可供测试覆盖路径。

## 2. 数据模型

```ts
interface Snippet {
  id: string;        // crypto.randomUUID()
  title: string;     // 可选；空时展示正文首个非空行
  content: string;   // 必填；保留原始换行/空白，复制逐字符一致
  group: string;     // 空串 = 未分组
  createdAt: number;
  updatedAt: number;
}
interface SnippetDb {
  format: "notevault-snippets-v1";
  snippets: Snippet[];
  updatedAt: number;
  order?: string[];  // 手动排序（id 从前往后）；缺省按 updatedAt 倒序
}
```

## 3. 双宿主命令

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `snippets_load` | 无 | 整库 `SnippetDb`（文件不存在返回空库） |
| `snippets_save` | `{ db }` | `{ ok: true }` |

- 三处登记：`shared/types.ts`、`src/api/client.ts`、`web/server.ts` + `src-tauri/src/api.rs`；
- 写盘：临时文件 + rename 原子写；文件损坏时 `load` 抛错，前端停止保存并提供重试，
  **不会覆盖原文件**；
- 不依赖笔记库，无 vault 时也可使用。

## 4. UI 布局（卡片网格）

```
顶栏：品牌 | 常用语（N 条） | 搜索 | 导入 | 导出 | 新建
├─ 左分组栏（172px）：全部 / 未分组 / 各分组（数量）；底部拖动提示
└─ 卡片网格：repeat(auto-fill, minmax(280px, 1fr))
     卡片 = 标题 + 分组徽标 + 正文预览（6 行截断）+ 更新时间 + 复制/编辑/删除
```

- 1280px 宽可同屏 3 列、常见窗口 6~12 张卡片，密度与可区分性平衡；
- 卡片正文等宽字体、`pre-wrap` 保留换行；超出 6 行截断，点击卡片查看全文弹窗；
- 编辑器弹窗：标题（可选）、分组（datalist 可输入新名称）、正文（必填，11 行）；
  Ctrl/⌘+Enter 保存；
- 深浅主题复用现有 CSS 变量，卡片/分组栏/弹窗均适配。

## 5. 交互

- **搜索**：标题/正文/分组大小写不敏感，先子串再退化为子序列；与分组过滤叠加；
  `Ctrl+P` 打开快速检索弹窗（Quick Open 风格：输入框 + 结果列表 + ↑↓/Enter/Esc，
  Enter 打开详情；空输入显示全部）；顶部内联搜索框保留；
- **分组**：自由文本，保存时输入新名称即创建；左栏显示每组数量；
- **复制**：一键复制正文原文（不 trim、不转义），卡片/详情均提供，1.2s 已复制反馈；
- **新建**：`Ctrl+N` 直接打开新建弹窗（输入框聚焦时同样生效），插入最前；
- **拖动排序**：卡片可拖动，左/右半区决定插到目标前/后，accent 指示线；
  松手立即写 `order` 并持久化；搜索或分组过滤时禁用拖动；
  Tauri 窗口配置 `dragDropEnabled: false`，避免原生拖放拦截 WebView2 的 HTML5 拖放；
- **桌面快捷键**：Tauri 启动后关闭 WebView2 浏览器加速键
  （`AreBrowserAcceleratorKeysEnabled=false`，setup 后台重试直到生效），
  使 `Ctrl+P` / `Ctrl+F` 等进入页面由前端处理；
- **编辑/换内容**不改变位置；**删除**二次确认；
- **导入/导出**：JSON 全量导出（按当前显示顺序 + 完整 order）；导入支持合并/替换，
  合并按 id 较新者胜、新增按来源顺序追加；
- **错误态**：加载失败显示错误与「重试加载」，暂停写入，避免损坏文件被覆盖。
