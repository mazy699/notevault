## 新增：对比工作台（Diff）

三种输入模式：

| 模式 | 用法 |
| --- | --- |
| **文件** | 输入两个文件绝对路径（记住上次输入），对比任意文本/代码/SQL 文件 |
| **文本** | 直接粘贴两段文本，即时对比 |
| **Git** | 输入 Git 仓库路径 → 读取跟踪文件列表 → 选文件自动加载提交历史（最多 200 条，--follow）→ 选择两个版本（含"工作区"）对比 |

### Diff 查看器（对标 IDEA / Beyond Compare）

- **双栏并排**（默认）/ **统一**视图切换；
- 删除行红底、新增行绿底，**行内差异字符**更深一档高亮；
- 长文件**自动折叠**未变更区段（上下文 3 行），点击折叠条展开；
- 双栏共用滚动容器，滚动天然同步；
- 统计条：+N 新增 / -M 删除 / 折叠块数 / 版本标签；
- "忽略空白"开关（比较时折叠空白，显示保留原文）；
- 交换按钮一键互换两侧；
- 大文件保护：超过 20000 行截断提示，行内高亮有上限。

### Git 对比安全性

git 命令仅只读操作（ls-files / log / show），参数数组调用不经 shell（防注入），
不修改仓库任何内容。

## 已知限制

- 不支持 Word/Excel 等二进制格式对比（设计如此）
- Git 模式需要本机安装 git 命令行
- 超大文件（>10 万行）建议使用专业 diff 工具
