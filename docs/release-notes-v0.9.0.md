# NoteVault v0.9.0

小版本更新：新增设置中心与可自定义快捷键，常用语支持 Ctrl+P 快速检索 / Ctrl+N 新建，
并修复桌面端拖动排序。

## 新增

### 设置中心（Issue #21）
- 活动栏左下角新增齿轮入口，独立懒加载设置页：
  - **通用与外观**：浅色/深色主题、读取工作台自动刷新；
  - **工作台启停**：对比 / 密码 / 工作日志 / 常用语可关闭（读取必需）；关闭后图标隐藏、
    快捷键失效但数据保留；
  - **快捷键**：工作台切换与常用语检索/新建可录制、清除、恢复默认，重复组合会提示冲突；
  - **密码库**：自动上锁分钟数迁移到设置中心（原有设置值继续生效）；
  - **关于**：版本、宿主类型、数据目录说明；
- 活动栏工作台 tooltip 实时显示当前快捷键。

### 快捷键调整
- 工作台切换默认改为 **`Alt+Shift+1~5`**（读取 / 对比 / 密码 / 工作日志 / 常用语），
  旧 `Alt+1~5` 不再默认生效；可在设置中心自定义；
- 常用语默认 `Ctrl+P` 快速检索、`Ctrl+N` 新建，且可自定义；
- 桌面端关闭 WebView2 浏览器加速键，使 `Ctrl+P` / `Ctrl+F` 等由应用处理。

### 常用语快速检索（Issue #20）
- `Ctrl+P` 打开 Quick Open 风格弹窗：输入框 + 结果列表 + ↑↓/Enter/Esc/点击外部，
  结果显示标题、分组、正文单行预览，Enter 打开详情；
- 顶部内联搜索框保留；`Ctrl+N` 直接打开新建弹窗（输入框聚焦时仍生效）。

## 修复

- **桌面端拖动排序失效**：Tauri 窗口关闭原生拖放拦截（`dragDropEnabled: false`），
  常用语卡片与密码列表在桌面端恢复真实鼠标拖动与 `order` 持久化；
- 旧版工作台快捷键与 Shift+数字（真实键盘 `! @ #…`）匹配问题，改用物理键 code 归一化。
