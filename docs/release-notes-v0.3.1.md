# NoteVault v0.3.1

对比工作台**布局与交互优化**（v0.3.0 用户反馈修复）。

## 修复与优化

### 布局修复（关键）
- **活动栏布局修复**：此前活动栏被渲染为顶部的横向图标条（挤在左上角），
  现已修复为**左侧竖向轨道**，正确贯穿全高，读取/对比工作台布局均正常。

### 对比工作台交互优化
- **文本模式自动对比**：两侧文本粘贴后自动开始对比（600ms 防抖），
  无需点击按钮；输入区自动折叠为摘要条（字符数 + 重新编辑按钮），
  Diff 占满整个工作台区域；
- **三个模式的结果独立记忆**：切换文件/文本/Git 页签不再串显上一个模式的
  对比结果，切回时恢复各自的结果；
- **模式按钮加大**：文件/文本/Git 分段按钮更高更宽，点击更容易；
- 统计条固定在工作台底部（不再随内容浮动）。
