# NoteVault · 杀毒软件拦截问题与发布说明

> 现象：在装有 **Symantec Endpoint Protection（SEP）** 的公司电脑上，
> 未签名的 NoteVault exe 被拦截并隔离：
> `Security Risk Found! Unproven Insight`（文件信誉不足）。

## 1. 为什么会被拦截

杀毒软件对 exe 的判定不只看"有没有病毒代码"，还依赖**云信誉评分**：

| 因素 | NoteVault 现状 |
| --- | --- |
| 代码签名证书 | ❌ 无（签名证书需付费，个人项目暂未购买） |
| 文件云信誉 | ❌ 新发布的文件没有任何累积信誉，Symantec 归类为 "Unproven Insight"（未证实） |
| 分发方式 | 免安装单文件 exe + 直接网络分发——这正是恶意软件的典型特征，启发式引擎天然敏感 |
| 文件元数据 | ✅ 已内嵌产品名/版本/描述（Tauri 自动嵌入） |
| 打包/混淆 | ✅ 无 UPX 等加壳（加壳会显著提高误报率） |

**结论**：这不是病毒，但"未签名 + 零信誉 + 单文件直接分发"的组合在
企业级杀软（Symantec SEP、McAfee、火绒企业版等）下几乎必然被拦截。
**任何绕过手段都只能缓解，无法根治**——根治只有一条路：购买代码签名证书。

## 2. 各场景的解决方案

### 2.1 公司电脑（有 IT 管理员）→ 首选让 IT 白名单

把以下信息发给公司 IT，让他们在 **Symantec Endpoint Protection Manager（SEPM）** 上操作：

```
文件 SHA256（v0.2.0 便携版）:
  见 release/checksums.txt（每个文件都有）
检测名称: Security Risk Found! Unproven Insight
说明: 开发者自用工具，MIT 开源，源码仓库可审计
```

IT 侧两种做法（二选一）：

1. **添加例外/排除项**：SEPM → 策略 → 病毒和间谍软件防护 → 集中例外 →
   按文件指纹（SHA256）添加 `NoteVault_0.2.0_portable.exe`；
2. **释放被隔离文件**：SEP 客户端 → 隔离区 → 还原 + 加入低风险策略。

> 提供按文件的 SHA256（而非目录排除）是 IT 最容易接受的方案——
> 这就是为什么 Release 里附带了 `checksums.txt`。

### 2.2 自助提交"误报申诉"（累积云信誉）

向杀软厂商提交误报申诉后，厂商会把文件加入云白名单，**全球用户的拦截都会消失**：

- **Symantec / Broadcom**：
  1. 把被拦截的 exe 用密码 `infected` 打包成 zip；
  2. 访问 Broadcom 的误报提交页（Security Response → Submit a False Positive / File Dispute）；
  3. 填写文件哈希（SHA256 见 `checksums.txt`）与说明（开源工具，MIT，仓库地址）；
  4. 通常 1-3 个工作日更新云信誉。
- **其他引擎**（可选）：VirusTotal 提交、Microsoft（提交误报样本页）、火绒/360 各有误报通道。
  多引擎申诉可以同时改善多个杀软的信誉。

### 2.3 个人电脑（自己有管理员权限）→ 手动放行

SEP 客户端弹窗通常有"更多详情/允许"入口；或：

1. SEP 客户端 → 设置 → 防病毒和 SONAR → 排除项；
2. 把 NoteVault 所在目录（如 `D:\Tools\NoteVault\`）加入排除。

> 建议：为 NoteVault 建一个固定目录并固定使用，排除一次即可长期有效。

### 2.4 不与杀软对抗 → 用 Web 版（公司电脑推荐）

Web 版**没有任何 exe**：它是一个 Node.js 脚本 + 浏览器页面。
Node.js 脚本不会被杀软当作可执行文件拦截，浏览器页面也不触发文件扫描：

```bash
# 解压源码后
npm install && npm run build && npm run web
```

这正是本项目提供双模式的原因——Web 版就是为"装不了软件"的场景设计的。

### 2.5 长期根治 → 代码签名证书（可选）

| 证书类型 | 大致年费 | 效果 |
| --- | --- | --- |
| OV（组织验证） | ~¥600-1500/年 | 签名后立即有基础信誉，需累积智能筛选信誉 |
| EV（扩展验证） | ~¥1500-3000/年 | SmartScreen 立即信任；SEP 等企业杀软大幅降低误报 |
| 自签/测试签 | 免费 | 只对本机有效，意义有限 |

如果这个工具在公司内推广给多人使用，向公司申请一张 OV/EV 证书是唯一彻底方案。

## 3. 版本发布规范（便于 IT 白名单）

- 每个版本的 exe 的 **SHA256 都记录在 Release 附带的 `checksums.txt`**；
- 版本号语义化：小版本迭代（0.1.x）尽量不改文件指纹太多次，减少 IT 反复加白；
- Release 附件与源码 tag 一一对应（可从 tag 重建产物核对）。

## 4. 事后自查清单

被拦截后建议自查一遍（NoteVault 已满足）：

- [x] exe 无加壳（未用 UPX 等）
- [x] 文件元数据完整（产品名/版本/公司）
- [x] 无网络行为异常（仅监听 127.0.0.1，无上传）
- [x] 无注册表持久化、无自启动
- [x] 源码完全开源可审计
