# NoteVault v0.8.0

小版本更新：新增「常用语」工作台，密码生成器支持自定义字符集，补充工作台快捷键与 Web 一键重建脚本。

## 新增

### 常用语工作台（Issue #12）
- 活动栏新增第 5 个工作台「常用语」，便签式管理常用回复 / SQL 片段 / 固定说明 / 命令；
- 卡片网格布局（自适应列宽，正文 6 行预览），支持标题、分组、搜索（标题/正文/分组模糊匹配）、
  一键复制原文（保留原始换行与空白）、点击卡片查看全文；
- 拖动卡片调整顺序并持久化；搜索/分组过滤时暂停拖动；
- 数据保存为 `%APPDATA%/notevault/snippets.json`（Web/桌面同路径同格式，原子写）；
- 支持 JSON 导入（合并 / 替换）与导出，方便迁移备份；文件损坏时暂停写入并提供重试。

### 密码生成器：自定义「仅允许字符」（Issue #11）
- 生成器规则区新增「仅允许」输入框：候选池 = 所选字符类 ∩ 允许字符 − 排除字符；
- 留空保持原有行为；某类求交为空自动跳过；不内置固定字符/长度规则，完全自定义。

### 工作台快捷键（Issue #15）
- `Alt+1~5` 全局切换读取 / 对比 / 密码 / 工作日志 / 常用语；
- 常用语工作台内：`/` 聚焦搜索、`N` 新建（输入框内与弹窗打开时不拦截）；
- 活动栏与按钮 tooltip 显示对应快捷键。

### Web 一键重新构建并启动（Issue #16）
- 新增 `重新构建并启动NoteVault-Web版.bat`：自动安装依赖、`npm run build`、生成 Web 包、
  停止旧服务并启动最新构建；构建失败时保留旧服务；
- 支持 `--no-open` 跳过打开浏览器。
