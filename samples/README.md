# NoteVault 示例笔记库

欢迎！这个目录是 NoteVault 的**示例笔记库**，用于演示与验证各类渲染能力。

## 目录导览

| 文件 | 演示内容 |
| --- | --- |
| [Mermaid图表示例.md](Mermaid图表示例.md) | 流程图 / 时序图 / 甘特图 / 饼图 |
| [功能特性/代码高亮与表格.md](功能特性/代码高亮与表格.md) | 代码块高亮、行内代码、GFM 表格、脚注 |
| [功能特性/数学公式.md](功能特性/数学公式.md) | 行内与块级 LaTeX 公式 |
| [功能特性/任务列表与引用.md](功能特性/任务列表与引用.md) | 任务列表、引用嵌套、删除线、内嵌 HTML |
| [相对链接测试/主页.md](相对链接测试/主页.md) | 笔记间相对跳转、图片相对路径 |
| [HTML展示/交互式图表报告.html](HTML展示/交互式图表报告.html) | 浏览器内核渲染：交互式图表（离线可用） |
| [HTML展示/纯样式页面.html](HTML展示/纯样式页面.html) | CSS 排版样例 |

## 使用提示

- 左侧树点击文件即可打开；`Ctrl+P` 快速打开；`Ctrl+Shift+F` 全文搜索；
- 渲染视图中每个代码块右上角有复制按钮；顶部工具条可切换「源码」并一键复制全文。

*本文件同时用于验证：列表、表格、粗体、行内代码 `code`、链接等基础 Markdown 元素。*
