# NoteVault v0.6.1

密码历史升级为**完整使用区间**（开始时间 → 结束时间），并明确**默认不启用主密码**。

## 变更

### 历史密码记录完整区间
- 每条历史密码现在记录 **开始使用时间** 与 **结束（被替换）时间**；
- 时间链自动衔接：首代从凭证创建时间起算，每代结束时间即下一代的开始时间；
- 详情页历史行显示 `开始 ~ 结束` 区间（右侧对齐、等宽数字），悬停可看精确时间；
- 详情页元信息改为"当前密码自 X 起 · 创建于 Y"；
- Markdown / CSV / JSON 导出的历史均包含 `startedAt` / `endedAt`；
- **旧数据兼容**：导入仅有 `changedAt` 的旧格式时自动推导开始时间
  （首代 = 创建时间，后续 = 前代结束时间），无需手动迁移。

### 默认不启用主密码
- 密码库开箱即用：默认明文存储、直接使用，不强制、不主动劝设主密码；
- 顶栏仍保留"主密码"入口，需要加密时随时可设置（AES-256-GCM + scrypt）；
- 相关提示文案调整为中性说明（"未加密（默认，开箱即用）"）。

- 单测 62/62（新增旧格式时间推导、区间导出断言）
- Web 实测：两次换密后历史区间正确衔接（第 1 代 创建~换密1、第 2 代 换密1~换密2，
  当前密码自换密2 起）；库文件含 `startedAt`/`endedAt` 且时间链完整
- 默认无主密码开箱可用，顶栏显示"未加密（默认）"
