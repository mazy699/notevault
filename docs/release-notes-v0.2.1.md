# NoteVault v0.2.1

界面细节优化版：**代码块与 Mermaid 块的右上角复制按钮全面重做**。

## 下载

| 文件 | 用途 |
| --- | --- |
| `NoteVault_0.2.1_setup.exe` | **安装版**（NSIS 向导，安装到当前用户目录，无需管理员权限） |
| `NoteVault_0.2.1_portable.exe` + `WebView2Loader.dll` | **免安装便携版**（两个文件放同一目录） |
| `checksums.txt` | 全部资产的 SHA256（供 IT 白名单/完整性校验） |

> 未签名 exe 可能被 Symantec 等企业杀软拦截，白名单指引见仓库 `docs/05-杀毒软件与发布说明.md`。

## 相对 v0.2.0 的变更

### 优化：代码块 / Mermaid 块的右上角复制

- 两种块的**块顶工具栏完全统一**：左上角语言标签（`ts` / `sql` / `mermaid`…），**右上角复制按钮**；
- 复制按钮改为带边框底色的明确按钮（此前是无边框的浅色图标，不易注意到可以点击）；
- 悬停按钮时以强调色高亮，点击后按钮短暂显示 ✓"已复制"反馈；
- Mermaid 块头部修掉了样式未套用的排版问题（此前语言标签与按钮错位换行），
  现在与代码块完全同构；
- 复制内容验证：代码块复制的是该代码块的原始文本，Mermaid 块复制的是图表源码。

### 其他

- 复制按钮支持自定义 tooltip（代码块"复制源码"/ Mermaid"复制 Mermaid 源码"）。

## 验证

- 单元测试 21/21、桌面冒烟 15/15；
- Web 模式实测：点击代码块复制按钮 → Windows 剪贴板收到代码块源码；
  点击 Mermaid 复制按钮 → 剪贴板收到 Mermaid 源码；
- 深色 / 浅色主题下块顶工具栏视觉均正常。
