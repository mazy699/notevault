# NoteVault v0.5.1

对比工作台的差异语义升级：**新增 / 删除 / 修改三种变化各有专属颜色**，
修改行额外展示**行内字符级差异**（改了哪几个字一目了然）。

## 变更

### 三色差异语义（三种对比模式统一）
- **绿色** = 新增行；**红色** = 删除行；**琥珀色** = 修改行（旧行与新行按位置配对）；
- 修改行的行内改动字符以**红/绿字符块**加深标出：旧行红块 = 被删掉的字符，
  新行绿块 = 新写入的字符——"同一行改了什么"不再需要肉眼比对；
- 统计条同步细分：`−N 删除 / +M 新增 / ≈K 修改` 三色显示。

### 文本对比（双框即时高亮）
- 配对逻辑升级：相邻的删除+新增行组按位置配对为"修改行"，
  不再整行红/绿一刀切；行内字符差异在背层实时渲染（600ms 防抖内即时更新）；
- 纯删除/纯新增行保持红/绿整行着色。

### 文件对比 / Git 历史对比（修复）
- 修复行级背景从未生效的问题（行容器缺失类型类名，此前着色全部来自
  字符块，纯删除/新增行完全无底色）：并排视图现按 equal/del/add/replace
  正确着色，空侧单元格灰色标注；
- 统一视图的修改对（−/+ 行）也改为琥珀底 + 字符块。
