# NoteVault v0.4.1

文本对比模式按用户反馈**重新设计为双框常驻即时高亮**（最终形态）。

## 变更

- **左右输入框即对比区域**：两侧文本粘贴后**直接在框内着色**（删除行红底、
  新增行绿底、行号列），没有任何模式切换或独立对比区域；
- 双框滚动即时同步，可直接在框内编辑，改动即时更新；
- 每框右下角显示 −N / +M 行数角标，顶部统计条显示删除/新增汇总；
- 修复叠层错位（textarea 左内边距与行号列宽对齐）与背层文字重影（背层文字透明）。
