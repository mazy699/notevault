# NoteVault v0.5.0

本版聚焦四件事：**PWA 应用化**、**WebUI 后台运行**、**对比工作台全面升级**、**深浅主题配色全面体检**。

## 变更

### WebUI 可安装为本地应用（PWA）
- 通过浏览器访问 NoteVault 时，顶栏出现**"安装应用"**按钮（支持安装的浏览器会捕获安装事件）；
- 安装后获得独立窗口的本地应用（开始菜单/桌面图标），无需保留网页标签；
- 新增 `manifest.webmanifest` 与轻量 Service Worker：只缓存带 hash 的静态壳
  （`/assets/`、图标），**API、笔记内容、库外文件一律不缓存**，保证数据实时性；
- 桌面版（Tauri）不受影响，不会注册 SW。

### WebUI 启动/关闭改为后台服务（学 Worklog）
- `启动NoteVault-Web版.bat`：服务以**独立后台进程**运行（关闭命令行不影响服务）；
  端口 8321 已监听时直接打开浏览器，不会重复启动；就绪后自动打开页面；
- 新增 `关闭NoteVault-Web版.bat`：按 8321 端口定位监听进程并结束
  （仅限 node 进程，端口被其他程序占用时跳过以防误杀）。

### 对比工作台
- **文本对比**：双框常驻、贴入即自动对比、框内行着色与行号对齐（v0.4.1 形态延续）；
- **Git 文件模糊搜索**：仓库文件列表支持子序列模糊过滤，回车即选；
- **文件模式路径智能提示**：输入框支持目录浏览 + 模糊过滤（上下键/回车），
  数据来自新增的 `fs_list_dir` 命令（Web 与桌面双宿主同契约实现，上限 2000 项）；
- **目录历史"路径不存在"提示**：Vault 菜单打开时逐个检测历史路径，
  失效路径红字标注"路径不存在"并降透明度；
- Git 文件列表上限 5000（双宿主一致）。

### 深浅主题体检
- 逐项目检代码块、Mermaid、diff 着色、搜索高亮在**深色与浅色主题**下的对比度，
  消除"白天好看黑夜看不清"的问题。
