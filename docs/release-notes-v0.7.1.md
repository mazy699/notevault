# NoteVault v0.7.1

小版本更新：文件/路径复制能力与状态栏优化。

## 新增

### 文件名 / 路径一键复制（Issue #2）
- **文件树 / 最近列表 / 全文搜索结果**：右键菜单 → 复制**文件名** / 复制**相对路径** / 复制**完整路径**（文件夹同样支持）；
- **已打开文件标签**：右键菜单同上（保留「关闭标签 / 关闭其他标签」）；
- **文件栏**：新增复制按钮（点开三选项）；
- **状态栏**：点击当前文件路径直接复制其**完整路径**；点击笔记库路径复制库根路径；
- 复制成功状态栏即时提示（如「✓ 已复制完整路径」）。

### 状态栏 Git 分支徽标
- 当前文件所在目录（未打开文件时为笔记库目录）位于 Git 仓库时，
  状态栏显示**当前分支徽标**（⎇ main），点击可复制分支名；
- 非 Git 仓库不显示；分离头指针显示「HEAD（分离）」。

## 修复

- 状态栏图标与路径因长路径被挤压换行（图标一行、路径一行）→ 改为单行
  inline-flex 布局，超长路径省略显示，不再换行。
