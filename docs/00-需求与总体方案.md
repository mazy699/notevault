# NoteVault · 需求与总体方案

> 一个面向「AI 开发过程文档」的本地笔记查看器：统一查看分散在各处的 Markdown / HTML 笔记，界面类似 Obsidian（左侧目录树 + 右侧渲染视图），只读查看为主，支持源码查看与一键复制。

## 1. 背景与问题

使用 AI 工具开发时会持续产出大量文档：

- 绝大多数是 **Markdown**，其中常含 **Mermaid 图**、代码块、表格、公式；
- 部分是 **HTML**（AI 生成的可视化报告），内容表现力更强；
- 分散在项目目录的各个角落。

现状痛点：

| 痛点 | 现状 |
| --- | --- |
| 打开工具不统一 | .md 用 VS Code/Obsidian，.html 用浏览器，来回切换 |
| 渲染质量参差 | VS Code 预览 mermaid/公式支持差；部分 .md 排版不清晰 |
| 无法全局查找 | 想在「整个笔记库」里搜一段话，没有统一入口 |
| 公司电脑安装受限 | 未签名安装包/便携 exe 可能被公司策略拦截 |

## 2. 产品定位

- **只读查看器**：不做编辑功能；提供「查看源码」与「一键复制源码」。
- **两种使用方式，功能完全一致**：
  1. **桌面版**：Tauri 2 打包的 Windows 免安装单文件 exe（无签名，能否运行取决于公司策略）；
  2. **Web 版**：本机启动一个 Node 服务（仅监听 127.0.0.1），浏览器访问——不受安装策略限制，且天然用浏览器内核渲染，HTML 呈现最完整。
- 参考项目：`D:\code\ai\zcode\tool`（WorkLog）的「同一前端 + IPC 命令面与 HTTP API 一一对应」双模式架构。

## 3. 功能需求（验收清单）

### 3.1 核心

| # | 需求 | 验收标准 |
| --- | --- | --- |
| F1 | 笔记库（Vault）目录树 | 左侧树展示所选目录下文件夹与笔记文件；文件夹可展开/收起；点击文件右侧打开 |
| F2 | 自动按格式渲染 | `.md/.markdown` 走 Markdown 渲染管线；`.html/.htm` 用 iframe 以浏览器内核渲染；`txt` 纯文本 |
| F3 | Markdown 渲染质量 | GFM 表格/任务列表/脚注、代码高亮、行内代码、引用、图片（相对路径可解析）、数学公式、**Mermaid 图渲染** |
| F4 | HTML 渲染 | 完整还原（含 JS 交互，如 ECharts）；提供「在浏览器中打开」 |
| F5 | 源码查看 | 渲染/源码视图切换（含快捷键 Ctrl+E）；源码带语法高亮 |
| F6 | 复制源码 | 一键复制当前文件原始内容；渲染视图中每个代码块也有复制按钮 |
| F7 | 全文搜索 | 跨整个笔记库搜索关键词，结果按文件分组、含上下文片段与命中高亮，点击跳转打开 |
| F8 | 文件名快速打开 | Ctrl+P 模糊搜索文件名并快速打开（Quick Open） |
| F9 | 多标签页 | 同时打开多个文件，标签可关闭；记录最近打开文件 |
| F10 | 主题 | 深色 / 浅色主题切换，跟随内容优化阅读体验 |
| F11 | 大纲 | Markdown 渲染时右侧可展开标题大纲（TOC），点击滚动定位 |
| F12 | 状态栏 | 显示当前文件完整路径、大小、修改时间、行数；可复制路径 |

### 3.2 使用体验

- F13 左侧栏宽度可拖拽调整；可折叠；
- F14 目录树内置过滤框（按名称即时过滤）；
- F15 快捷键：Ctrl+P 快速打开、Ctrl+Shift+F 全局搜索、Ctrl+B 侧栏开关、Ctrl+E 源码切换、F5/Ctrl+R 刷新；
- F16 刷新机制：手动刷新按钮 + 可选「自动刷新」（轮询文件修改时间，外部改动后自动更新树与打开的文件）；
- F17 记忆：上次打开的笔记库、主题、布局等设置持久化（桌面版存本地设置文件，Web 版存服务端设置文件）；
- F18 空状态引导：未选笔记库时显示欢迎页与操作指引；
- F19 相对链接跳转：Markdown 内指向其它笔记的相对链接可在应用内打开。

### 3.3 交付物

- D1 桌面版：`release/NoteVault_<版本>_portable.exe`（免安装单文件）；
- D2 Web 版：`启动NoteVault-Web版.bat` 一键启动 + 浏览器访问；
- D3 设计文档（本目录）；
- D4 示例笔记库 `samples/`（覆盖各类渲染特性，兼作测试集）。

### 3.4 非目标（明确不做）

- 编辑/保存笔记；
- 笔记内建标签、双链、知识图谱；
- 云同步、多人协作；
- 移动端适配（桌面浏览器与桌面窗口为主）。

## 4. 关键约束

1. **公司电脑可运行性优先**：Web 版为兜底使用方式，零依赖安装（仅需本机已有 Node.js），服务仅绑定 127.0.0.1；
2. 桌面版免安装：Tauri 构建产物 `target/release/*.exe` 直接可用（依赖系统自带 WebView2）；
3. 全部渲染资源本地化（mermaid/katex/highlight 均随包内置），**离线可用**；
4. 中文界面与中文文件名完全支持（UTF-8 读取，兼容 GBK 回退）；
5. 只读安全：任何模式都不提供写文件能力；Web 服务含路径穿越防护。

## 5. 总体方案（一句话版）

**一个 React 前端 + 一份「channel/payload」API 契约，两个宿主**：Web 宿主是零依赖 Node HTTP 服务，桌面宿主是 Tauri 2（Rust）；前端通过适配层自动识别宿主并路由 API 调用与文件 URL。
