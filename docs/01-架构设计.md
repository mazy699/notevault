# NoteVault · 架构设计

## 1. 总体架构

```
┌────────────────────────────────────────────────────────────┐
│                     React 前端 (src/)                       │
│  布局 / 文件树 / 渲染器(md·html·源码) / 搜索 / 标签页 / 主题  │
│                    │                ▲                       │
│        api/client.ts│(call)        │fileUrl()/absFileUrl()│
│  ┌──────────────────┴────────────────┴───────────────────┐ │
│  │                宿主适配层 (adapter)                     │ │
│  │  Tauri: invoke("api",{cmd,payload}) + vault:// 协议    │ │
│  │  Web  : POST /api/<cmd>          + /vault/<rel> 静态路由│ │
│  └───────────────────────┬───────────────────────────────┘ │
└──────────────────────────│─────────────────────────────────┘
            ┌──────────────┴──────────────┐
            ▼                             ▼
   Web 宿主 (web/server.ts)        桌面宿主 (src-tauri, Rust)
   零依赖 node:http                Tauri 2 + 自定义 vault 协议
   fs 读取 / 搜索 / 设置            fs 读取 / 搜索 / 设置 / 对话框
   仅监听 127.0.0.1                单文件免安装 exe
```

两宿主实现**同一份 API 契约**（`shared/types.ts`），前端不感知差异。

## 2. 目录结构

```
html-note-app/
├─ docs/                 # 设计文档（本目录）
├─ samples/              # 示例笔记库（测试集 + 最终功能验证素材）
├─ shared/types.ts       # API 命令名、请求/响应类型（前后端唯一契约）
├─ src/                  # React 渲染层
│  ├─ api/client.ts      # 宿主适配层：call() + fileUrl() 家族
│  ├─ stores/            # zustand：vault / tabs / ui
│  ├─ lib/               # 纯工具（路径、格式化、markdown 预处理）
│  └─ components/        # layout / tree / viewer / search / common
├─ web/server.ts         # Web 宿主：零依赖 node:http
├─ src-tauri/            # 桌面宿主：Tauri 2
│  └─ src/ (main.rs, api.rs, fsops.rs, settings.rs, vault_proto.rs)
├─ scripts/              # 图标生成 / 便携包整理 / 启动脚本
└─ release/              # 免安装 exe 输出（gitignore）
```

## 3. API 契约（channel/payload）

所有业务调用都是 `call(cmd, payload) → Promise<result>`：

| cmd | payload | 返回 | 说明 |
| --- | --- | --- | --- |
| `vault_info` | `{path?}` | `VaultInfo` | 当前笔记库信息；不传 path 表示读取持久化的最近笔记库 |
| `vault_pick` | `{}` | `VaultInfo \| null` | 桌面版弹出目录选择框；Web 版返回 null（由前端输入路径） |
| `vault_set` | `{path}` | `VaultInfo` | 设置当前笔记库并持久化（两宿主均维护 vault_history 最近列表） |
| `vault_list` | `{}` | `string[]` | 最近使用过的笔记库绝对路径列表 |
| `fs_tree` | `{refresh?}` | `FileNode` | 笔记库目录树（已按规则过滤） |
| `fs_read` | `{path}` | `FileContent` | 读取文本文件（UTF-8，GBK 回退，BOM 剥离；仅读前 5MB） |
| `fs_stat` | `{paths:[]}` | `{path:{mtimeMs,size}}` | 批量取 mtime/size（保留命令，当前前端未使用） |
| `fs_snapshot` | `{}` | `{entries:{path:{mtimeMs,size}}, truncated}` | 全库文件时间戳快照（自动刷新 diff，>8000 文件 truncated=true） |
| `fs_search` | `{query, caseSensitive?}` | `SearchResult` | 全文搜索（md/html 剥离标签后正文搜索，默认不区分大小写） |
| `settings_get` | `{key}` | `string \| null` | 服务端持久化设置 |
| `settings_set` | `{key,value}` | `void` | 同上 |
| `reveal_in_explorer` | `{path}` | `void` | 仅桌面版：资源管理器中定位 |
| `open_external` | `{path}` | `void` | 两宿主：系统默认程序打开（URL 交给系统浏览器） |
| `__ping` | `{}` | `{ok, host}` | 连通性检查（区分宿主） |

**约定**：
- 所有路径参数都是**相对笔记库根的 POSIX 风格路径**（`a/b/c.md`）；仅 `vault_set` / `open_external` / `reveal_in_explorer` 接受绝对路径；
- 错误统一为 `Error(message)`，message 直接可展示给用户（中文）。

### 文件 URL 家族（图片 / iframe / 相对链接）

| 场景 | Web 宿主 | Tauri 宿主 |
| --- | --- | --- |
| 笔记库内相对资源 | `/vault/<relpath>` | `convertFileSrc(rel, "vault")` → `http://vault.localhost/<relpath>` |
| 绝对路径资源（md 里写死的绝对路径） | `/raw?path=<abs>` | vault 协议 `~abs/<encoded-abs>` 分支 |

两宿主的 vault 路由都按「相对于笔记库根」解析，因此 HTML 文件里的相对引用（`./img.png`、`style.css`）在 iframe 中天然可用。

## 4. Markdown 渲染管线

```
md 原文
 → 预处理（换行规范化、mermaid 块标记）
 → remark-gfm（表格/任务列表/删除线）
 → remark-math + rehype-katex（公式）
 → rehype-raw（允许内嵌 HTML）
 → rehype-highlight（代码高亮，highlight.js）
 → react-markdown 组件覆写：
     code.mermaid → Mermaid 组件（动态 import mermaid，主题联动）
     img  → src 重写到 vault URL（相对/绝对/http 原样）
     a    → 相对 .md/.html 链接应用内打开；外链系统浏览器
     pre  → 包一层带「复制」按钮的代码块容器
```

- mermaid 动态 import（首屏不加载 ~1MB 包）；主题跟随应用主题（dark/light），主题切换时全量重渲染；
- 单文件渲染上限 5MB，超限提示改用源码视图。

## 5. HTML 渲染策略

- `<iframe>` 指向 vault URL，`sandbox="allow-scripts allow-same-origin allow-forms allow-popups allow-modals"`；
- 理由：AI 生成的 HTML 常含交互脚本（ECharts 等），保真优先；内容来源是用户本机自己的文件；
- 顶部工具条：在浏览器打开 / 复制源码 / 刷新；
- Web 版直接 `/vault/...` 同源加载；Tauri 版走 vault 自定义协议。

## 6. Web 宿主设计（web/server.ts）

- 零第三方依赖，纯 `node:http` + `node:fs`（与参考项目 WorkLog 相同的做法）；
- `POST /api/<cmd>`：JSON in/out，路由表与契约一一对应；
- `GET /vault/*`：按 MIME 静态吐出笔记库内文件（真实文件名路径，保障相对引用）；防路径穿越（resolve 后必须仍在库根内）；
- `GET /raw?path=`：吐出库外绝对路径文件（md 中偶发绝对路径引用图片）；同样禁止目录列表；
- 仅监听 `127.0.0.1`；`--port` / `--open` / `--vault` 参数；`%APPDATA%/notevault/settings.json` 持久化设置；
- 前端静态资源从 `dist/` 提供，SPA 回退 index.html。

## 7. 桌面宿主设计（src-tauri）

- Tauri 2，`app.windows` 单窗口 1440×900；
- 单一命令 `api(cmd, payload)` 内部分发到 `fsops.rs` / `settings.rs`，与 Web 路由同构；
- `register_uri_scheme_protocol("vault")`：按路径吐文件（MIME 按扩展名），支持 `~abs/` 前缀的绝对路径分支；
- 插件：`dialog`（选目录）、`clipboard-manager`（复制源码兜底）；
- 设置存 `%APPDATA%/notevault/settings.json`（Windows；其他平台 `~/.local/share/notevault/`，与 Web 宿主一致），用 std::env 实现避免多余依赖；
- `--smoke` 参数：命令行模式下对临时目录跑一遍 fsops 核心函数并打印 `SMOKE_RESULT=...` 后退出（无 UI 冒烟测试）；
- 打包：`tauri build`，取 `target/release/notevault.exe` 为免安装单文件（资源已内嵌）。

## 8. 前端状态（zustand）

| store | 状态 |
| --- | --- |
| `useVaultStore` | vaultPath、tree、树加载态、自动刷新开关 |
| `useTabsStore` | tabs[]（path、title、kind、viewMode）、activePath、recents[] |
| `useUiStore` | 主题、侧栏宽/折叠、右侧大纲开合、搜索面板开合、quickOpen 开合 |

文件 mtime 缓存放在 tabs store（自动刷新 diff 用）。

## 9. 自动刷新（F16）

- 间隔 4s 轮询 `fs_snapshot`（全库 mtime 快照，阈值：≤8000 文件才自动启用）；
- 与上次快照 diff：新增/删除/修改 → 更新树；当前打开文件 mtime 变化 → 重新读取并渲染（保留滚动位置顶部提示「内容已刷新」）。

## 10. 安全设计

| 面 | 措施 |
| --- | --- |
| Web 服务暴露面 | 仅 127.0.0.1；Host 头必须为本机地址（防 DNS rebinding）；API 仅接受同源 `application/json` 请求且校验 Origin/Sec-Fetch-Site（防 CSRF）；请求体 ≤1MB |
| 路径穿越 | `/vault/*` 与 `fs_read` 均 normalize 后断言在库根内；dist 静态服务断言带分隔符前缀；符号链接/junction 一律跳过 |
| Markdown 内嵌 HTML | rehype-sanitize 消毒（禁 script/事件处理器/javascript: URL，保留 AI 文档常用表现元素与 KaTeX/MathML） |
| HTML iframe | sandbox（无 allow-same-origin，脚本在隔离 origin 运行，交互保真）；「浏览器打开」走系统浏览器完整渲染 |
| 库外绝对路径 | `/raw`（Web）与 vault 协议 `~abs/`（桌面）仅允许图片类文件，禁止 HTML/JS MIME；无 CORS 通配头 |
| CSP | 桌面版配置非空 CSP（禁外部脚本源）；Web 版依赖 sanitize + 同源策略 |
| 大文件 | 读取只取前 5MB；搜索跳过 >2MB 文件；快照/树限制数量上限并在超限时报告 truncated |
| 主线程 | 桌面版命令 async + spawn_blocking，重 IO 不阻塞 UI |

## 11. 技术选型清单

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 前端框架 | React 19 + TypeScript + Vite | 与参考项目一致，本机验证过 |
| 样式 | Tailwind CSS 4 | 原子化 + 深浅主题用 CSS 变量 |
| 状态 | zustand | 轻量 |
| Markdown | react-markdown + remark-gfm + rehype-raw + rehype-highlight | 参考项目同款 |
| 图表 | mermaid 11（动态 import） | AI 文档高频 mermaid |
| 公式 | remark-math + rehype-katex | AI 文档常见公式 |
| 图标 | lucide-react | 轻量树摇 |
| Web 宿主 | node:http（零依赖） | 免安装、可审计 |
| 桌面宿主 | Tauri 2（Rust） | 单文件免安装、体积小 |
