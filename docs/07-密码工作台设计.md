# 07 · 密码工作台设计（v0.6.0）

> 本地密码记录器 + 强密码生成器，作为 NoteVault 第三个工作台。
> 场景：记录公司常见系统（邮箱 / 工号系统 / 数据库 / 服务器等）的账号密码，
> 定期轮换强密码并保留历史；支持导出迁移与备份；可选主密码加密。

## 1. 存储选型：JSON 文件（不用 SQLite）

| 维度 | JSON 单文件 | SQLite |
| --- | --- | --- |
| 双宿主一致性 | Web/Rust 均为现成文件读写 | Web 需 node:sqlite（Node 22.5+）或 npm 依赖；Rust 需 rusqlite 编译 |
| 导出/迁移 | 导出格式即存储格式，零转换 | 需额外转换层 |
| 数据量 | 几十~数百条 ≤ 几百 KB，足够 | 过剩 |
| 备份 | 复制一个文件 | 复制 db 文件（同） |

**结论**：`%APPDATA%/notevault/passwords.json`（两宿主同路径、同格式）。

## 2. 数据模型

```ts
interface PwDb { format: "notevault-pw-v1"; entries: PwEntry[]; updatedAt: number }
interface PwEntry {
  id: string; title: string; category: string;   // 邮箱/工号系统/数据库/服务器/网站/其他…
  account: string; password: string; url?: string; notes?: string;
  updatedAt: number; createdAt: number;
  history: { password: string; changedAt: number }[];  // 旧→新
}
```

- **密码历史**：任何"更换密码"（详情面板生成器 / 编辑表单改密码）都会把旧密码
  以 `changedAt=现在` 追加进 history；
- 生成器自动避让该条目"当前密码 + 全部历史密码"（最多重试 80 次）。

## 3. 加密（可选主密码）

- 存储格式（加密时整文件替换）：
  ```json
  { "format": "notevault-pw-enc-v1", "kdf": "scrypt",
    "salt": "<b64 16B>", "nonce": "<b64 12B>", "data": "<b64 ct||tag>" }
  ```
- KDF：scrypt **N=2^15, r=8, p=1 → 32B key**（Node `scryptSync({cost,blockSize,parallelization})` ↔ Rust `scrypt::Params::new(15,8,1,32)` 严格一致）；
- 加密：**AES-256-GCM**，密文后追加 16B tag（两宿主原生实现一致）；
- 主密码错误 = GCM tag 校验失败；主密码只存会话内存，不落盘；
- **跨宿主互操作已实测**：Web(Node) 加密 → 桌面(Rust) 解锁 ✓，反向 ✓。
- 锁态防护：加密且未解锁时，内存 `db` 是空占位，`persist()` 一律拒绝写盘
  （顶栏导入/导出/主密码按钮同时禁用），防止空库覆盖磁盘加密库。

## 4. 密码生成器

- CSPRNG（`crypto.getRandomValues` + 拒绝采样防模偏差）；
- 规则：长度 8~128（滑块+数字）、大写/小写/数字/符号四类开关、
  排除字符集（内置"排除易混淆 O0oIl1|`'\" "预设可切换 + 手动追加）；
- 保证：每个启用类至少出现一次（代表字符先放置后洗牌）；
- 强度：按实际字符类别合成池大小估算熵（<40 弱 / <60 中 / <80 强 / ≥80 极强）；
- 会话内最近 5 次生成记录（点击复制）。

## 5. 导入 / 导出

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| JSON | 整库（含历史），`JSON.stringify(db, null, 2)` | **迁移主格式**，无损 roundtrip |
| CSV | title,category,account,password,url,notes,updatedAt,createdAt,history(JSON列)；带 BOM | Excel 查看/编辑 |
| Markdown | 按分类分组报表，密码行内代码、历史列表、风险提示 | 人读/打印归档 |

- 导入：`<input type=file>`（WebView2/浏览器原生文件对话框，双端零新命令）；
  解析内容自动识别 JSON/CSV；确认弹窗显示条数并选择 **合并**（同 id 或同名同账号
  取 updatedAt 较新者）或 **替换整库**（替换前有醒目警告）；
- 导出（桌面）：`save_text_file` 命令弹系统"另存为"对话框写盘；
  导出（Web）：Blob + `a.download` 浏览器下载。

## 6. UI 结构

```
活动栏（第三个图标 KeyRound）
└─ 顶栏：品牌 | 凭证库 / 密码生成器页签 | 已加密/未加密徽标 | 导入 | 导出▾ | 主密码
   ├─ 凭证库：左列（搜索 + 分类 chips + 条目列表 + 新增）
   │   └─ 右侧：详情（账号/密码遮蔽+显隐+复制/地址/备注/强度）、
   │       更换密码面板（内嵌生成器，自动避让历史）、历史密码折叠列表
   ├─ 密码生成器：独立页签（规则 + 结果 + 强度 + 会话历史）
   └─ 弹窗：解锁卡片 / 主密码设置 / 导入确认
```

设计细节：
- 密码默认遮蔽（12 个圆点），**复制始终复制真值**（不因遮蔽复制到圆点）；
- 分类 chips 显示每类数量，点击过滤；搜索覆盖标题/账号/URL/备注；
- 所有样式复用现有 CSS 变量（浅深主题自动适配，已截图目检）。

## 7. 安全边界（如实告知）

- 未设主密码时，passwords.json 为**明文**（等同记事本），界面以"未加密"徽标提示；
  建议设置主密码；
- 导出文件（JSON/CSV/MD）**必然是明文**（否则无法迁移），用完请妥善保管；
- 主密码遗忘无法找回（GCM 校验无后门）；重新开始只能删除 passwords.json；
- 本工具不做浏览器自动填充，复制后请手动粘贴。
