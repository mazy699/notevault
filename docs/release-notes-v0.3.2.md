# NoteVault v0.3.2

对比工作台**新增品牌顶栏**，与读取工作台视觉完全统一。

## 新增

- 对比工作台顶栏：品牌标识（N NoteVault）+ 模式切换大按钮
  （文件对比 / 文本对比 / Git 版本对比）+ 视图切换（并排|统一）+
  忽略空白 + 交换，全部收纳在顶栏，层级更清晰；
- 工具条仅保留随模式变化的输入区。
