# NoteVault v0.4.0

对比工作台三大易用性增强（v0.3.x 用户反馈）。

## 新增

### 文本对比：左右双框即时高亮
- 左右两个输入框常驻，**粘贴文本即时着色**（删除行红底、新增行绿底，无需任何按钮）；
- 双框滚动即时同步，可直接在框内编辑，改完即时更新；
- 统计条常显：−N 行删除 / +M 行新增。

### Git 对比：文件模糊搜索
- 文件选择改为**模糊搜索下拉**：输入文件名片段即时过滤（如输入"设计"匹配 3 个设计文档）；
- 大仓库友好（跟踪文件上限 5000，下拉最多显示 50 条）。

### 文件对比：路径智能提示
- 输入路径时**去掉文件名即浏览该目录**：下拉列出目录内全部文件，按名字模糊过滤；
- 也可点击输入框旁的 🔍 按钮主动浏览目录；
- 支持点选子目录逐层进入。

### 文件对比：分区错误提示
- 文件不存在时在**对应侧的区域**显示"文件不存在"及路径提示（左侧缺失提示在左区，右侧缺失提示在右区）；
- 一侧可读时仍显示该侧读取成功，便于核对路径。

## 笔记目录历史增强

- 目录切换菜单中的历史记录会检测路径有效性：**路径已不存在时显示提示**，避免误点。
