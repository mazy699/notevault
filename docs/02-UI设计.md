# NoteVault · UI 设计

## 1. 设计原则

1. **阅读优先**：内容区是绝对主角，chrome（框架）元素全部低对比、可退后；
2. **Obsidian 式空间记忆**：左树右文、多标签、大纲侧栏，位置固定可预期；
3. **克制的精致**：细边框 + 微圆角 + 少量阴影 + 一处强调色，不堆装饰；
4. **深浅双主题**均为一等公民（深色默认，观感专业；浅色为阅读优化）；
5. 信息密度可调：侧栏可折叠、大纲可收起、状态栏常驻但低调。

## 2. 整体布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶栏 TopBar (40px)                                                    │
│ [☰] [✦ NoteVault] [📁 笔记库名 ▾]        [🔍] [🌙/☀] [↻] [⚙]        │
├──────────────┬─┬──────────────────────────────────────────┬──────────┤
│ 侧栏 Sidebar  │║│ 标签栏 TabBar (36px)                      │ 大纲      │
│ (默认 280px,  │║│ [📄 架构设计.md ×] [📄 报告.html ×] [＋]   │ Outline  │
│  可拖拽 180-  │║├──────────────────────────────────────────┤ (240px,  │
│  480px, 可折  │║│ 文件工具条 FileBar (36px)                 │  可折叠)  │
│  叠)          │║│ [渲染|源码]  …spacer…  [📋复制] [🌐浏览器]  │          │
│              │║├──────────────────────────────────────────┴──────────┤

│──────────────│║│                                                     │
│ [📁 文件]     │║│                                                     │
│ [🔍 搜索]     │║│              内容区 Content                          │
```

- 侧栏三个页签：**文件 / 搜索 / 最近**（图标切换），顶部常驻过滤框；
- 分隔条（║）可左右拖拽（180–480px），双击恢复默认宽度；
- 大纲面板仅 Markdown 文件时自动出现，可手动收起；
- `Ctrl+B` 折叠侧栏；折叠后 [☰] 恢复。

## 3. 色彩系统

CSS 变量定义于 `:root`（浅色）与 `html.dark`（深色），组件一律引用变量。

| 变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | #ffffff | #1e1f22 | 应用底色 |
| `--bg-panel` | #f7f8fa | #232428 | 侧栏/顶栏/标签栏 |
| `--bg-hover` | #ececf0 | #2a2b30 | 悬浮 |
| `--bg-active` | #e2e4ea | #313239 | 选中/激活 |
| `--border` | #e3e5ea | #35363c | 边框 |
| `--text` | #24292f | #d7dadd | 主文字 |
| `--text-secondary` | #57606a | #9ea1a8 | 次要文字 |
| `--text-faint` | #8b949e | #6e7076 | 弱化文字 |
| `--accent` | #6d5bd0 | #8b7bff | 强调色（选中、链接、按钮） |
| `--accent-soft` | rgba(109,91,208,.12) | rgba(139,123,255,.16) | 强调底色 |
| `--ok / --warn / --err` | 绿/橙/红 | 同 | 状态语义 |

Markdown 正文（`--md-*`）：代码底色、行内代码红字、引用竖线、表格斑马纹等单独定义。

## 4. 关键组件设计

### 4.1 顶栏
- 左：应用 logo（✦ + NoteVault，纯 CSS/SVG 文字标识）；
- 笔记库按钮：显示当前库名，点击弹出面板——最近使用过的库列表 + 「打开其他目录…」（桌面版调系统对话框，Web 版输入路径）；
- 右：搜索、主题切换（图标随主题变化）、刷新、（设置留白位）。

### 4.2 文件树
- 行高 28px，缩进 12px/级，悬浮显示整行底色；
- 文件夹：`▸/▾` chevron + 文件夹图标 + 名称，子项数角标（可选）；
- 文件：类型图标带色（**md=蓝紫 M**、**html=橙 </>**、txt=灰、图片=青、其他=灰淡）；
- 打开中的文件：accent 色文字 + 左侧 2px accent 竖条；
- 过滤框：输入即时过滤（保留命中文件的父链），无结果显示空状态；
- 树加载中显示骨架屏；空库显示引导。

### 4.3 标签栏
- 标签 = 类型图标 + 文件名 + ×；激活标签底部 2px accent 线；
- 超出宽度横向滚动（滚轮纵向映射为横向；触控板横向滑动原生支持）；激活标签自动滚入可见区；滚动条弱化隐藏；
- 右侧固定「全部标签」下拉按钮：按当前顺序列出全部标签（类型图标 + 文件名 + 相对路径 + 关闭），顶部搜索框实时过滤，↑↓/Enter 键盘切换，Esc/点击外部关闭；标签溢出时按钮高亮；
- 中键/×关闭；右键菜单：关闭/关闭其他/复制路径/在资源管理器中显示。

### 4.4 文件工具条
- 左：视图分段控件 `渲染 | 源码`（仅 md/html）；html 额外有 `在浏览器打开`；
- 右：复制源码（图标+文字）、刷新、关闭；
- HTML 文件渲染时提示「已使用浏览器内核渲染」小徽标。

### 4.5 内容区
- **Markdown**：居中排版列 `max-width: 860px`，上下留白 32px；prose 样式覆盖标题层级、代码块（macOS 式三点头部 + 语言名 + 复制钮）、表格（全边框+斑马纹）、引用、图片（圆角+可点击放大原始尺寸）、mermaid 卡片容器（浅色底、边框、可横向滚动）；
- **源码视图**：等宽字体 + 行号 + 语法高亮（highlight.js），同样居中列；
- **HTML**：iframe 占满内容区（无 prose 包装），顶部细提示条可关；
- **图片文件**：棋盘格底 + 图片居中自适应；
- **txt**：等宽纯文本。

**链接行为（Issue #7，Markdown / HTML 预览统一）**：
- 库内相对链接、库根相对链接 → 应用内标签打开（已打开则激活，不重复）；
- `http(s)` / `mailto` / `file:` 绝对路径 → 桌面版交系统默认程序，Web 版新浏览器标签；
- 纯 `#anchor` 仍在当前页内滚动；
- HTML 预览由宿主在 `?nv_preview=1` 响应中注入点击拦截脚本，经 postMessage 转交宿主处理；
  iframe 不加 `allow-top-navigation`，脚本/表单功能不受影响。

### 4.6 搜索面板（侧栏页签）
- 输入框 + 「区分大小写 / 整词」开关 + 结果统计（N 个文件 · M 处命中）；
- 结果按文件分组：文件名行（图标+相对路径+命中数）→ 命中行片段（**命中词高亮**，最多显示 5 行/文件）；
- 点击片段行：打开文件并跳转到首个命中位置（渲染视图滚动到对应标题/文本，源码视图滚动到行）。

### 4.7 Quick Open（Ctrl+P）
- 居中浮层：输入框 + 模糊匹配文件列表（路径+图标+得分高亮），↑↓ 选择、Enter 打开、Esc 关闭；
- 空输入时列出最近文件。

### 4.8 大纲面板
- 标题层级树（h1–h4），等宽缩进，当前滚动位置高亮；
- 点击平滑滚动到对应标题。

### 4.9 状态栏
- 左：笔记库绝对路径（点击复制）；
- 右：当前文件相对路径 · 大小 · 修改时间 · 行数。

### 4.10 空状态 / 欢迎页
- 未选库：居中卡片——logo、一句话说明、大按钮「打开笔记目录」、两种使用方式说明；
- 空标签页：快捷键速查卡（Ctrl+P / Ctrl+Shift+F / Ctrl+B / Ctrl+E）。

### 4.11 常用语工作台（Issue #12）
- 活动栏第 5 个图标（StickyNote），标题「常用语工作台（快捷文本）」，懒加载；
- 顶栏：品牌 | 常用语（N 条）| 搜索 | 导入 | 导出 | 新建；
- 左侧分组栏 172px：全部 / 未分组 / 自定义分组（数量），底部拖动提示；
- 卡片网格 `repeat(auto-fill, minmax(280px, 1fr))`：标题 + 分组徽标 + 正文预览
  （等宽字体、6 行截断）+ 更新时间 + 复制/编辑/删除；点击卡片打开全文弹窗；
- 新建/编辑弹窗：标题（可选）、分组（可输入新名称）、正文（必填，保留原始换行）；
- 拖动卡片左/右半区决定插到目标前/后，accent 指示线；搜索/分组过滤时禁用拖动；
- 详见 `docs/09-常用语工作台设计.md`。

### 4.12 设置中心（Issue #21）
- 活动栏左下角齿轮按钮进入，懒加载独立设置页；
- 分区：通用与外观（主题 / 读取自动刷新）、工作台（对比/密码/工作日志/常用语启停，
  读取必需；禁用后隐藏图标与快捷键、数据保留）、快捷键（工作台与常用语检索/新建，
  点击录制、清除、恢复默认、冲突提示）、密码库（自动上锁分钟数）、关于
  （版本 / 宿主 / 数据目录）；
- 设置保存于 `%APPDATA%/notevault/settings.json` 的 `app_settings` 键；
  默认工作台快捷键 `Alt+Shift+1~5`，常用语 `Ctrl+P` / `Ctrl+N`；
- 活动栏工作台 tooltip 显示当前绑定。

## 5. 交互细节

| 场景 | 行为 |
| --- | --- |
| 点击树文件 | 打开/激活标签，滚动到顶部 |
| 双击树文件 | 同上（预留给「固定标签」未实现） |
| 文件外部被修改 | 自动刷新开启时静默更新，状态栏闪一次「已刷新」 |
| 渲染视图内相对链接 | 应用内新标签打开目标笔记；外链桌面版系统浏览器、Web 版新浏览器标签 |
| 复制源码按钮 | 复制后按钮短暂变为 ✓ 已复制 |
| 主题切换 | 全部即时生效（含 mermaid 重渲染、代码高亮主题切换） |
| 快捷键 | Ctrl+P 打开 / 常用语快速检索、Ctrl+N 新建常用语、Ctrl+Shift+F 搜索、Ctrl+B 侧栏、Ctrl+E 渲染/源码、Ctrl+W 关标签、F5 刷新；Alt+Shift+1~5 切换工作台（默认，可在设置中心自定义） |

## 6. 字体

- UI：`system-ui, "Segoe UI", "Microsoft YaHei"`；
- 正文（Markdown）：同 UI 字体 + `"Georgia"` 仅标题不特殊处理，保持系统一致性；
- 等宽：`"Cascadia Code", Consolas, "JetBrains Mono", monospace`；
- 字号基准 14px（UI）/ 16px（Markdown 正文），内容区支持 Ctrl+滚轮缩放（浏览器默认行为保留）。
